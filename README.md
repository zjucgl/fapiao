# 发票登记管理系统（fapiao）

一个轻量的个人/小团队发票登记管理系统。

- **多团队隔离**：超级管理员开团队，团队管理员管操作员，操作员上传发票。
- **PC + 手机通用**：响应式 Web，无需安装 App。
- **图片私密存储**：原始发票图与支付凭证图存阿里云 OSS 私有桶，访问走签名 URL。
- **批量导出**：管理员一键导出 Excel + 图片 ZIP，方便交财务/报销。

> 本仓库当前为需求与设计阶段，尚无代码实现。
